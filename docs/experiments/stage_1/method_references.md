# 方法参考与本地适配边界

FK steering 将多个扩散轨迹作为粒子，并依据中间势函数的分数重采样；原研究覆盖图像和文本生成。[原论文发布页](https://proceedings.mlr.press/v267/singhal25b.html)

本实验的 FK 实现使用 PocketXMol clean prediction 的宽松键长、内部接触和口袋接触势，采用差分 reward 权重并复制整个父图、置信历史和 reward 历史。奖励、分子变量、转移和评估任务均为本地适配，因此称为 FK 风格适配；不据此宣称严格复现原论文或将原论文的收益直接迁移到分子生成。实现及冻结参数以本目录协议、manifest 和源码快照为准。

IPR 的核心是在已有样本上对部分区域重新加噪，并在保留区域的条件下重新生成。原论文面向 sequential diffusion 和区域间混合噪声条件，不依赖外部 verifier。[原论文摘要与版本页](https://arxiv.org/abs/2605.19317)

本实验使用冻结的 PocketXMol SBDD 图采样器，固定选择25%原子，比较随机与内部置信度选择，同时更新选中原子的坐标、类型及关联键。它是分子局部重加噪对照；分子图的离散键/类型、化学重建及全图条件与原论文的区域任务不同。未选区域的原始状态保持与化学重建后的芳香性/键级变化分别审计，结果不能表述为原论文 IPR 方法的一般性成败。

本文只说明来源和实现边界；实验效力与 Stage2 选择必须依据本实验完整配对结果、实际 NFE、重复计时和 guardrails。
